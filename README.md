# 채용공고 매칭 분석기 (Job Matcher)

채용공고와 내 이력서를 붙여넣으면 필요한 기술 스택을 뽑아 **매칭 점수**, **부족한 스킬**, **보완 방법**을 알려주는 웹 서비스입니다.

- 데모: (Vercel 배포 후 링크 추가)
- 스택: Next.js 16 (App Router), TypeScript, Tailwind CSS, Vitest
- 현재 버전: **v0 — 규칙 기반 분석기** (AI API 없이 동작)

## 문제

취업 준비를 하며 공고를 수십 개씩 읽다 보면, 공고마다 내가 가진 스킬과 부족한 스킬을 비교하는 데 시간이 많이 듭니다. 이 비교를 자동화해 "어떤 공고에 지원할지", "무엇을 더 공부할지"를 빠르게 판단하려고 만들었습니다.

## 동작 방식

```
[브라우저] 공고 + 이력서 입력
     │  POST /api/analyze
     ▼
[서버] getAnalyzer() ── v0: 규칙 기반 분석기 (현재)
     │                └─ v1: Claude API 분석기 (예정)
     ▼
결과: 점수 · 필수/우대 스킬 매칭 · 강점 · 보완 제안
```

- **분석은 서버에서** 합니다. v1에서 Claude API를 붙일 때 API 키가 브라우저에 노출되지 않게 하기 위해서입니다.
- 모든 분석기는 같은 `Analyzer` 인터페이스(`src/lib/types.ts`)를 따릅니다. 분석기를 바꿔도 화면과 API 코드는 그대로 둡니다.

### v0 규칙 기반 분석기

1. 스킬 사전(`src/lib/skills.ts`, 50여 개 스킬)의 영문·한글·약어 표기로 공고와 이력서에서 스킬을 찾습니다.
2. 공고를 줄 단위로 읽으며 `자격요건` / `우대사항` / `복지` 같은 제목으로 구역을 판단해 필수·우대를 나눕니다.
3. 필수 2점, 우대 1점 가중치로 0~100점 매칭 점수를 계산합니다.

해결한 문제:

- `Java`가 `JavaScript` 안에서 잘못 잡히는 문제 → 긴 표기부터 찾고, 찾은 부분을 지운 뒤 다음 표기를 찾음
- 한글 조사(`리액트를`) 때문에 단어 경계 검사가 실패하는 문제 → 영문 표기에만 경계 검사 적용
- `- Docker 경험 우대` 한 줄 때문에 아래 필수 항목까지 우대로 분류되는 문제 → 목록 항목은 구역 제목으로 보지 않음

## v0의 한계 (v1에서 개선할 점)

- **사전에 없는 스킬은 못 찾습니다.** 새로운 기술이나 회사별 용어를 놓칩니다.
- **비슷한 스킬을 인정하지 못합니다.** 공고가 "PostgreSQL 등 관계형 DB"라고 해도, 이력서의 MySQL을 부족으로 판단합니다.
- **경험 수준을 모릅니다.** "React 3년 이상"과 "React 사용 경험"을 구분하지 못합니다.

→ v1에서는 Claude API의 구조화 출력으로 분석하고, **같은 평가용 공고 20개로 v0와 v1의 정확도를 비교**할 예정입니다.

## AI와 어떻게 일했나

- AI에게 맡긴 것: 프로젝트 뼈대, UI 컴포넌트 초안, 스킬 사전 초안, 테스트 케이스 초안
- 내가 결정한 것: 분석기 인터페이스 설계, 필수/우대 가중치, 구역 판단 규칙, 오탐 케이스 정의
- 개발 기록: [`docs/DEVLOG.md`](docs/DEVLOG.md)

## 실행 방법

```bash
npm install      # 처음 한 번만
npm run dev      # http://localhost:3000 에서 확인
npm test         # 분석기 단위 테스트 (11개)
```

## 결과

- 분석 속도: 공고 1건당 약 1~10ms (v0, 규칙 기반)
- 테스트: 단위 테스트 11개 통과
- (v1 이후 정확도·비용 비교 결과 추가)
